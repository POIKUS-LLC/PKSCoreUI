## [0.1.0] - 2026-07-02

### Added
- Initial scaffold: theme token system (`PKSCoreUITheme`, color/typography/spacing/shape/elevation/motion/icon tokens),
  `PKSCoreUI.configure(_:)` MainActor theme provider with live propagation, accessibility infrastructure
  (`PKSAccessibility`, `PKSContrastValidator`), themed base classes (`PKSThemedView`, `PKSThemedControl`),
  v1 components (`PKSButton`, `PKSCardView`, `PKSBannerView`, `PKSListRowView`/`PKSListRowCell`, `PKSBadgeView`,
  `PKSEmptyStateView`, `PKSLoadingStateView`, `PKSErrorStateView`, `PKSToastView`, `PKSAlertPresenter`,
  `PKSActivityShareController`), screen shell (`PKSContentState`, `PKSStatefulViewController`), `PKSCoreUITestSupport`.
